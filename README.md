# Custom Tooltip

A simple implementation of custom tooltips using HTML, CSS, and JavaScript. This functionality replaces the default browser tooltip for any element that has a "title" attribute with a custom, stylish, and dynamically positioned tooltip.

## Features

- **Custom-Styled Tooltips:** No third-party plugins; just plain CSS for a neat appearance.
- **Dynamic Positioning:** Tooltips reposition on mouse movement to avoid overflowing the viewport.
- **Responsive & Flexible:** Automatically wraps long text and adapts to different element styles.

## Demo

To see the tooltip in action, simply open the `index.html` file in your browser. The demo includes various elements with tooltips, including one near the bottom of the page to demonstrate dynamic positioning.

## Getting Started

Clone or download this repository, then open `index.html` in your browser to test the custom tooltip functionality.
